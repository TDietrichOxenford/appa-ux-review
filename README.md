# Appa UX Review

Create a complete responsive UX evaluation website for a university UX/UI project about the mobile application **¡appa!**, an app for shopping malls in Argentina.

IMPORTANT:

- Build the entire website in ONE generation.

- This is an academic UX evaluation document, NOT a commercial landing page.

- Use the Spanish content exactly as provided below.

- Do not rewrite, summarize, invent or change the evaluation findings.

- Use the attached screenshots in the exact cards indicated below.

- The same screenshot may be reused in more than one card when indicated.

- Do not create fake app screenshots.

- Do not add backend functionality, authentication, databases, forms or unnecessary features.

- The final project must be suitable for GitHub and deployment on Vercel.

==================================================

GENERAL VISUAL STYLE

==================================================

Use a clean, modern, professional academic UX-research aesthetic inspired by the visual identity of ¡appa!.

Visual guidelines:

- White or very light neutral background.

- Soft mint/green accents inspired by ¡appa!.

- Black or dark gray typography.

- Rounded cards.

- Thin subtle borders.

- Generous but efficient spacing.

- Clear visual hierarchy.

- Minimal design.

- Avoid unnecessary animations.

- Responsive for desktop and mobile.

- All main sections must use the SAME wide content container.

- Do NOT make the homepage narrower than the evaluation sections.

- Cards should be easy to scan and compare.
